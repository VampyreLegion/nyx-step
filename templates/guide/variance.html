🎲 Variance Protocol

The Variance Protocol systematically introduces randomization entropy across batch generations so each take in a multi-output run is musically distinct. Instead of generating N variants from a single batch (which share one seed), it submits N individual one-shot workflows, each with its own seed, CFG, denoise, and prompt variant.

How It Works

When you enable Variance Protocol in the Parameters tab and set a Variations count:

  1. Seed randomization — each variant gets a fresh random seed (unless Lock Seed is on, in which case all variants share the base seed)
  2. CFG sweep — CFG Scale is randomly sampled from a range (default 1.5–3.5) per variant instead of a fixed value
  3. Denoise variation — denoise strength is randomized between 0.85–1.0 for slight acoustic variation
  4. Prompt cycling — the prompt library in NyxStudio-Config.json rotates through 10+ curated music-description templates, cycling across variants so each take is oriented by a different sonic target
  5. Step jitter — the step count varies by ±1 around your base setting to avoid lockstep artifact patterns

Configuration

All variance parameters live in NyxStudio-Config.json at the repo root:

KeyDefaultDescription
global_randomizationtrueMaster toggle (overridden by UI checkbox)
batch_strategy"increment"How prompts cycle through the library
seed_mode"random_per_index"Each variant gets an independent random seed
cfg_range[1.5, 3.5]Low/high bounds for CFG randomization
denoise_range[0.85, 1.0]Low/high bounds for denoise randomization
prompt_library10 entriesArray of comma-separated tag strings cycled per variant

Usage Tips

  • Start with 3 variations — enough variety to compare without overwhelming the ComfyUI queue
  • Lock seed + Variance Protocol = variants differ only in CFG, denoise, and prompt choice (not random seed), useful for isolating which parameter matters most
  • Edit the prompt library — add your own genre/tag combinations to NyxStudio-Config.json to bias the variant pool toward your preferred sonic palette
  • Each variant is a separate job card — you can Score, LRC, Remix, and download each independently
