📻 Continuous AI Radio

What It Does

Radio mode generates an endless stream of AI-composed music. A local Ollama model writes each song from scratch — choosing chord progressions, rhythmic feel, lyrics, and vocal style — then Nyx-Step renders it with ACE-Step. Each completed segment feeds back as a timbre reference for the next, keeping the stream sonically coherent.

An optional Icecast stream is available at http://192.168.1.109:8000/nyx-radio (LAN only) via Liquidsoap on Astraea — tune any audio player to that URL to listen.

Modes

ModeHow It Works

Auto DJ — Genre Picker

The Auto DJ panel has a Genre dropdown with 150+ genres (same library as the Style Infusor tab). Selecting a genre fills the Style Prompt field with matching tags and sets BPM/Key/Scale to the genre defaults. The prompt remains fully editable — tweak it or erase it for fully random selection. The 🎲 Random button picks a style from the built-in DJ library instead.

How It Works

  1. Ollama (gemma4:latest by default) receives a detailed musical brief and writes: song name, style tags, caption, and full lyrics with section markers ([Verse], [Chorus], etc.)
  2. Segment 0 — rendered fresh from the Ollama-generated params
  3. Segments 1+ — each uses the previous segment's audio as ReferenceTimbreAudio timbre input; Ollama writes a fresh song for every segment so the music evolves continuously
  4. A background watcher thread monitors ComfyUI; on completion it submits the next segment automatically
  5. The browser receives segment events over SSE (GET /radio/events) and queues playback; Liquidsoap simultaneously pulls files from GET /radio/next-for-stream for the Icecast feed

Playback

  • Segments play back-to-back in the browser automatically; "Now Playing" shows song name and style
  • History panel lists all completed segments with song name, style, replay (▶) and download (⬇) buttons
  • Icecast stream at http://192.168.1.109:8000/nyx-radio mirrors the same audio for external players
  • If you refresh the page while radio is running, it reconnects and resumes automatically

Settings Tips

  • Use turbo model (8 steps, ~15–20 s render) for near-real-time streaming with minimal gaps
  • Keep Duration ≤ 45 s so the next segment is ready before the current one ends
  • Ollama generation adds ~10–20 s per segment — budget this into your expected gap time
  • Auto DJ with no style override gives the most variety; locking a genre keeps the DJ focused on one sound
