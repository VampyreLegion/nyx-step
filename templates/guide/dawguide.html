🎚 The DAW — Multi-Track Studio

The 🎚 DAW tab is a full in-browser digital audio workstation built on the Web Audio API. Arrange your generated clips and stems on a timeline, mix them, apply effects, time-stretch, launch loops live, and bounce the whole thing to a WAV — all without leaving Nyx-Step. Projects autosave to the server and reload exactly as you left them.

Getting started

  1. Open the 🎚 DAW tab. A project loads automatically (or click + New).
  2. The 📚 Clip Library at the bottom lists every song you've generated and every stem you've split. Drag a chip onto a track lane to place it.
  3. Press ▶ to play, ⏸ pause, ⏹ stop. The transport shows playhead / total time.
  4. Everything autosaves — the ✓ saved indicator confirms. Switch projects from the dropdown; Rename / 🗑 manage them.

Timeline arranger

  • Tracks — + Add Track adds a lane. Each header has Mute (M), Solo (S), a volume slider, and a 🎵 button to generate straight onto that track.
  • Clips — drag to move (across tracks too), drag the right edge to trim. The left/right corner handles set fade-in / fade-out; the fade curve is drawn on the clip.
  • Zoom with 🔍− / 🔍+. Click the ruler to move the playhead.
  • Clip menu (the ⋯ on a clip) — Split at playhead, Normalize, Gain, Reset fades, plus the AI and stretch operations below.

Snap to grid

The Snap checkbox + resolution selector (Bar / ½ / Beat / ¼) snap clip placement to a tempo grid derived from the project tempo. Faint grid lines are drawn on the lanes so you can see where things land.

  • Snapping applies to dropping, moving, trimming, and stretching clip edges.
  • Hold Ctrl while dragging to temporarily bypass snap for fine adjustment.
  • Grid resolution follows the tempo — change tempo and the grid re-derives.

Time-stretch

Stretch a clip's length on the timeline independently of how much source audio it contains.

  • Plain drag of the right edge = trim (how much of the source plays).
  • Alt + drag the right edge = time-stretch (snaps to the grid, so you can stretch a clip's end onto a bar line).
  • The clip menu has ⇔ Time stretch… (enter a target % of original), a 🔒 Pitch lock toggle, and ↺ Reset stretch.
  • Varispeed (default): instant, but pitch changes with speed (like tape varispeed) — slower = lower.
  • Pitch lock on: preserves pitch while changing length (SoundTouch). The first playback after enabling renders the stretched audio in the background, then plays pitch-locked.
  • Stretch is clamped to 0.25×–4×. Reset returns a clip to 1× (unstretched).

Mixer & FX

Click 🎚 Mixer for channel strips — dB faders, pan, mute/solo, level meters, and a master fader. Each strip has an FX button opening per-track inserts:

EffectControls
EQ3-band — Low / Mid / High, ±12 dB
ReverbWet amount (generated impulse)
DelayTime / Feedback / Wet

Each effect has an on/off toggle; off = neutral (no colouration). FX settings persist with the project and apply to both timeline playback and the session grid.

Wave editor & AI operations

  • Split / Normalize / Gain / Fades from the clip menu for precise edits.
  • 🤖 AI Remix… — send a clip back through ACE-Step for a variation, extension, or repaint; the result drops into the library and onto a track.
  • 🎛 Split to Stems — run Demucs on a clip to break it into vocals / drums / bass / other as four new tracks (the source is muted).
  • 🎵 Generate onto track — generate a fresh clip directly onto a chosen track from the track header.

Session grid (looper)

Click 🎛 Session for a clip-launch grid — one column per track, scene rows.

  • Drag a library clip into a cell, then click the cell to loop it live through that track's chain (its volume / pan / mute / FX all apply).
  • One active cell per column — launching another in the same track replaces it; click the active cell to stop.
  • ⏹ Stop All clears everything; + Scene adds a row.
  • Free-launch (no quantization) — built for layering loops of any length on the fly. Independent of the timeline transport.

Export

⬇ Export WAV bounces the whole arrangement offline through the same graph as playback — volume, pan, mute/solo, fades, FX, and time-stretch (including pitch-lock) are all baked into a 16-bit WAV download.

Tips

  • Generate a few clips first so the library has material to arrange.
  • Set the project tempo before arranging so the snap grid matches your material.
  • Use Split to Stems on a full song, then mute/solo and re-balance the stems with the mixer + FX.
  • For tempo-matched loops in the session grid, time-stretch clips with pitch lock so they stay in key.
  • Everything is non-destructive — your original generated files are never modified; the project just references them.
