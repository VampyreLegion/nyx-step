✨ What's New in v3.12.0

🧠 Quick Idea Starter — Deep AI Expand

The Quick Idea Starter in Legion's BioInfusor is now a full song-generation agent. Type a simple idea like "Tiesto style live set" and it:

  • Researches the artist/idea — runs a Brave Search to gather real context about the artist's style, genre, and production
  • Generates full production tags — 8-15 rich Nyx-Step tags spanning genre, mood, instruments, performance technique, and sonic texture
  • Creates complete lyrics — multi-section song with Intro, Verse, Chorus, Bridge, Outro in the artist's lyrical style
  • Selects vocal tags — appropriate voice type, register, and style descriptors matching the genre
  • Populates every field — BPM, key, scale, time sig, instruments, vocals, tags, lyrics, song name all set automatically
  • Auto-generates — after a brief preview delay, clicks Generate so you get a finished track without touching anything

One click from a plain-English phrase to a finished musical output.

🎲 Variance Protocol

The Variance Protocol systematically randomizes each generation in a multi-output run so every take is musically distinct. Enable it in the Parameters tab — set a Variations count (1–8) and each variant becomes its own job card.

  • Per-variant seed randomization — each gets a fresh random seed (or shares Lock Seed if enabled)
  • CFG sweep — CFG Scale randomly sampled from a configurable range (default 1.5–3.5)
  • Denoise variation — denoise randomized between 0.85–1.0 for slight acoustic differences
  • Prompt cycling — rotates through a 10-entry prompt library from NyxStudio-Config.json
  • Step jitter — step count varies by ±1 around your base setting
  • N individual workflows — instead of one batch-N job, submits N one-shot workflows so each variant gets truly independent sampling

Full details in Guide → 🎲 Variance Protocol.

v3.11.1 — ID3 Metadata on Generated Files

🏷 ID3 Metadata on Generated Files

Generated audio files now carry rich ID3 tags written at creation time. The BPM, Key, Genre, and Song Name you set in the UI are embedded directly into the file, not just stamped at download time.

  • BPM — written to the TBPM frame (MP3) or bpm field (FLAC)
  • Key — written to the TKEY frame (MP3) or initialkey field (FLAC), e.g. "C Major", "F Minor"
  • Genre — written to the TCON frame (MP3) or genre field (FLAC)
  • Central tagger — core/tagger.py with tag_file() (in-place at creation) and tag_bytes() (download path); shared by job tracker and download endpoint
  • Survives everything — tags are on the original file, not a temp copy; ZIP exports, SMB shares, and direct file access all get the metadata

v3.11.0 — Browser DAW

🎚 Browser DAW

The headline feature: a full in-browser digital audio workstation in the 🎚 DAW tab. Arrange your generated clips and stems on a multi-track timeline and bounce the result to a WAV — see the dedicated 🎚 DAW guide for the full walkthrough. Highlights:

  • Timeline arranger — drag clips/stems from the library onto tracks; move, trim, fade, split, normalize; zoom and scrub.
  • Mixer + FX — dB faders, pan, mute/solo, meters, and per-track EQ / Reverb / Delay inserts.
  • AI operations — 🤖 AI Remix a clip, 🎛 Split to Stems (Demucs), and 🎵 Generate straight onto a track.
  • Session grid — a clip-launch looper: drop clips into per-track cells and trigger them live through the mixer/FX.
  • Snap to grid — snap placement/edges to a tempo grid (Bar/½/Beat/¼) with visible grid lines; hold Ctrl to bypass.
  • Time-stretch — Alt+drag a clip edge (or enter a %) to stretch; varispeed by default, or pitch-lock to keep the key.
  • Export WAV — bounces the whole arrangement (volume/pan/fades/FX/stretch) to a 16-bit WAV.
  • Clip copy/paste & duplicate — ⧉ Duplicate (back-to-back) plus Ctrl+C / Ctrl+V to paste at the playhead.
  • Single-instrument generate — 🎵 Generate onto a track with a Type (Instrument/Vocals/Drums/Bass) returns only that instrument/voice, not a full mix; optional 🔪 stem-isolate.
  • MIDI tracks + piano roll — convert a clip to MIDI (melody/rhythm/piano), edit notes in a full piano-roll, play via a built-in synth or a hardware synth over USB MIDI, and export.

Full DAW walkthrough in Guide → 🎚 DAW.

Tagging & Song-Creation Toolkit (v3.10.0)

Eight features focused on better tagging and faster, smarter song creation. They chain together: score a take → apply the suggested fixes on the same seed → A/B compare the results → Insights learns which tags work for you.

1. Smarter Lint Rules

The Lint tab now catches five more issues that quietly hurt generations:

RuleWhat it catches
Lyrics without a vocal tagYou wrote sung lyrics but no female vocal / male vocal / choir — the model will pick a random voice
Sections vs durationEach section needs ~12 s; warns when your section count can't fit the Duration (e.g. 8 sections in 30 s)
Genre / instrument conflictCombinations like acoustic folk + 808 bass or orchestral + distorted guitar
Overlong sung linesLines past ~16 syllables get crammed by ACE-Step — split them
Genre buried lateAttention favours early tokens; put the genre first

2. Quality Score → Fix Suggestions

Click 📊 Score on any finished job. Beyond the 0–10 grade, the score now diagnoses each weak dimension and proposes concrete tag fixes — e.g. a bass-heavy mix suggests adding bright, crisp, airy; a quiet track suggests punchy, powerful.

An ✨ Apply & Retake button appears when there are actionable fixes. It re-generates the track with the same seed and the remedy tags appended — so the only thing that changes is the fix, letting you hear exactly what it did.

3. Seed A/B Compare

Every job card has 🅰 and 🅱 buttons. Set one take as A and another as B to get a side-by-side player panel with the tag differences highlighted. When both takes share a seed, the panel confirms it — so you know the difference comes from the tags, not random variation. The ideal workflow: 🎲 lock a seed, change one tag, generate, compare.

4. History Insights

The History tab has a 📈 Insights button. It mines your own scored generations and shows your best-performing and weakest tags by average quality. A tag has to appear in at least two scored tracks before it shows, so score a handful of takes first to build the picture. This is personalised best-practice from your own data.

5. Artist Profile — Full Apply

In Legion's BioInfusor, an artist lookup's Apply to state now also sets Genre, Key, and Scale (parsed from the artist's vocal range), not just instruments and vocal tags. Key/scale are only applied when the lookup returns them in a recognisable form (e.g. "sings in G major"); otherwise they're left untouched.

6. Auto-Tag from Reference Audio

After analysing a track in the Analyze tab, click 🏷 Suggest Tags. The local Ollama model reads the detected BPM, key, chords, and lyrics and infers genre + style tags, appending them to your prompt. Turns "Analyze → Apply" into a full style starting point, not just the numeric fields.

7. Negative Prompting (Avoid field)

The Parameters tab has a new 🚫 Avoid field. Comma-separated qualities you want to steer away from (e.g. vocals, muddy bass, distortion) are wired into the diffusion model's negative conditioning. More reliable than trying to positively prompt around something you don't want. Experimental — effectiveness varies by model and tags.

8. Golden Presets

The preset list now ships with 16 built-in "Golden" presets — curated, known-good tag combinations per genre (Lo-Fi Study, Synthwave Drive, Epic Cinematic, Jazz Trio Night, Festival EDM, and more). Loading one sets the full state including the right model, steps, and CFG for that style. They can't be deleted, and your own preset with the same name takes priority.

Tips for Combining Them

  • Start from a Golden preset closest to your target, then refine.
  • Run Lint before generating to catch structure/tag problems early.
  • After a take, 📊 Score it and use ✨ Apply & Retake to fix issues without losing the seed.
  • 🅰/🅱 compare the original and the fix to confirm the change helped.
  • Over time, check 📈 Insights to learn which tags consistently score well for you.
