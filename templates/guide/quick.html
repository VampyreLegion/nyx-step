🧠 Quick Idea Starter — Deep AI Expand

The Quick Idea Starter in Legion's BioInfusor tab is a one-click song-generation agent. Type any musical idea in plain English — it handles everything from research to final generation.

How It Works

  1. You type a description — e.g. "Tiesto style live set", "dark ambient forest at midnight", "Billie Eilish type beat with trap drums"
  2. AI researches — if the description references an artist or known style, Gemma4 + Brave Search gather real context about the artist's genre, instruments, vocal style, and production approach
  3. AI generates complete song package — a single Ollama call produces:
    • 8-15 rich comma-separated Nyx-Step tags (genre, mood, instruments, performance style, texture)
    • BPM, key, scale, time signature, genre, mood
    • 4-8 instrument names populated into the instrument list
    • 3-6 vocal style tags (voice type, register, effects)
    • Full lyrics — multi-section song with [Intro], [Verse], [Chorus], [Bridge], [Outro] in the appropriate style
    • Creative song title
  4. Fields populate — every UI field is filled: tags, lyrics, instruments, vocal tags, BPM, key, scale, song name
  5. Review & Generate — the Generate tab opens so you can inspect and tweak everything, then click 🎵 Generate Music Idea when ready

Tips

  • Be specific about artists — mentioning an artist name triggers Brave Search for real context; "Tiesto style" gets better results than just "electronic"
  • Include mood/energy — "dark aggressive techno" vs "uplifting melodic techno" steers the lyrics and tag selection significantly
  • Edit before generating — all fields are populated but not submitted; you can freely tweak tags, lyrics, or parameters before clicking Generate
  • Instrumental? — check the "Instrumental only" box before clicking Expand; the AI will write arrangement notes instead of sung lyrics
