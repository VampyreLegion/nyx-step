🎚 The DAW — Multi-Track Studio

The 🎚 DAW tab is a full in-browser digital audio workstation built on the Web Audio API. Arrange your generated clips and stems on a timeline, mix them, apply effects, time-stretch, launch loops live, and bounce the whole thing to a WAV — all without leaving Nyx-Step. Projects autosave to the server and reload exactly as you left them.

Getting started

  1. Open the 🎚 DAW tab. A project loads automatically (or click + New).
  2. The 📚 Clip Library at the bottom lists every song you've generated and every stem you've split. Drag a chip onto a track lane to place it.
  3. Press ▶ to play, ⏸ pause, ⏹ stop. The transport shows playhead / total time.
  4. Everything autosaves — the ✓ saved indicator confirms. Switch projects from the dropdown; Rename / 🗑 manage them.

Timeline arranger

  • Tracks — + Add Track adds a lane. Each header has Mute (M), Solo (S), a volume slider, and a 🎵 button to generate straight onto that track.
  • Clips — drag to move (across tracks too), drag the right edge to trim. The left/right corner handles set fade-in / fade-out; the fade curve is drawn on the clip.
  • Zoom with 🔍− / 🔍+. Click the ruler to move the playhead.
  • Clip menu (the ⋯ on a clip) — Split at playhead, Duplicate, Normalize, Gain, Reset fades, plus the stretch, AI, and MIDI operations below.

Copy / paste / duplicate

  • ⧉ Duplicate (after) in the clip menu drops a back-to-back copy right after the clip — click once to turn a 30 s clip into 60 s, again for 90 s.
  • Ctrl+C copies the selected clip; Ctrl+V pastes it at the playhead on its track (snapped to the grid).

Snap to grid

The Snap checkbox + resolution selector (Bar / ½ / Beat / ¼) snap clip placement to a tempo grid derived from the project tempo. Faint grid lines are drawn on the lanes so you can see where things land.

  • Snapping applies to dropping, moving, trimming, and stretching clip edges.
  • Hold Ctrl while dragging to temporarily bypass snap for fine adjustment.
  • Grid resolution follows the tempo — change tempo and the grid re-derives.

Time-stretch

Stretch a clip's length on the timeline independently of how much source audio it contains.

  • Plain drag of the right edge = trim (how much of the source plays).
  • Alt + drag the right edge = time-stretch (snaps to the grid, so you can stretch a clip's end onto a bar line).
  • The clip menu has ⇔ Time stretch… (enter a target % of original), a 🔒 Pitch lock toggle, and ↺ Reset stretch.
  • Varispeed (default): instant, but pitch changes with speed (like tape varispeed) — slower = lower.
  • Pitch lock on: preserves pitch while changing length (SoundTouch). The first playback after enabling renders the stretched audio in the background, then plays pitch-locked.
  • Stretch is clamped to 0.25×–4×. Reset returns a clip to 1× (unstretched).

Mixer & FX

Click 🎚 Mixer for channel strips — dB faders, pan, mute/solo, level meters, and a master fader. Each strip has an FX button opening per-track inserts:

EffectControls
EQ3-band — Low / Mid / High, ±12 dB
ReverbWet amount (generated impulse)
DelayTime / Feedback / Wet

Each effect has an on/off toggle; off = neutral (no colouration). FX settings persist with the project and apply to both timeline playback and the session grid.

Wave editor & AI operations

  • Split / Normalize / Gain / Fades from the clip menu for precise edits.
  • 🤖 AI Remix… — send a clip back through ACE-Step for a variation, extension, or repaint; the result drops into the library and onto a track.
  • 🎛 Split to Stems — run Demucs on a clip to break it into vocals / drums / bass / other as four new tracks (the source is muted).
  • 🎵 Generate onto track — generate a fresh clip directly onto a track from its header. Pick a Type (Instrument / Vocals / Drums / Bass — auto-switches to Vocals when your tags mention a voice); the request is augmented with isolation tags and negative conditioning so you get only that instrument/voice, never a full mix. Tick 🔪 Isolate (stem-split after) for a hard guarantee (runs Demucs and keeps the matching stem).
  • 🎹 Convert to MIDI… — transcribe a clip to a MIDI track (see below).

MIDI tracks

The DAW has full MIDI tracks alongside audio tracks. Add one with + Add MIDI Track, or create one by transcribing audio. USB MIDI devices use the browser's Web MIDI API:

  • Plug in before you start the browser — Web MIDI only sees devices that were connected when the browser launched. After connecting new hardware, fully quit and reopen.
  • Firefox (snap on Nyx) needs a one-time grant — the first MIDI request makes Firefox auto-offer a site permission add-on for this site. Install it, Allow MIDI access, then reload. If the MIDI in selector shows "MIDI:" plus a hint, follow it and reload.
  • Outputs — hardware synths appear in the track's Output selector only after Web MIDI is working.
  • Audio → MIDI — a clip's 🎹 Convert to MIDI… transcribes it to notes: Melody (monophonic pitch), Rhythm (percussive onsets), or Piano (polyphonic). The new MIDI track lines up under the source clip.
  • Internal synth — notes play through a built-in synth routed via the track's chain, so the mixer + FX apply. The track header has a waveform selector (sine / triangle / sawtooth / square).
  • External USB MIDI — the header's Output selector lists Internal synth plus any hardware synths connected over USB MIDI; pick one to drive your hardware instead. (WAV export captures the internal synth only — hardware-routed tracks export silent.)
  • MIDI notes render as blocks on the timeline lane and are included in Export WAV (via the internal synth).

Piano-roll editor

Double-click a MIDI lane (or the 🎹 button in its header) to open the piano-roll — a scrollable pitch×time grid with a clickable piano keyboard down the left.

  • Draw — click an empty cell to add a note (snapped to the grid; row = pitch). It plays a preview blip.
  • Move — drag a note (time snaps, pitch follows the row). Resize — drag its right edge.
  • Delete — Delete/Backspace on the selected note, or double-click it.
  • Velocity — the toolbar slider sets the selected note (0–127); note brightness reflects it.
  • Preview — click any key on the left to hear that pitch through the track's synth. Hold Ctrl while dragging to bypass snap.

Recording — MIDI-in & audio-in

Capture live performances straight into the timeline. Arm one or more tracks (the red ● on a track header), then press the transport's ● REC button. Play your part, then press ● STOP — the transport's ⏹ stop button also finalizes a take.

  • MIDI tracks — connect a keyboard over USB MIDI and pick it in the MIDI in selector (or leave auto for the first input found). NoteOn/NoteOff with velocity are captured as piano-roll notes on the armed track, timed against the DAW's audio clock so they land correctly whether or not the transport is playing.
  • Audio tracks — the browser microphone records straight into an audio clip at the record start position. Pick a specific mic in the Mic selector or use the default. Recordings upload to daw_imports/ and join the clip library for dragging anywhere.
  • Live monitoring — while recording, MIDI tracks running the internal synth play your keys in real time through the track's chain (volume / mute / FX apply). Tracks routed to a USB MIDI output send notes to your hardware synth instead, so you can record into the hardware's sound.
  • Metronome — the Click checkbox plays a beat-synced tick at the project tempo while recording; switch project tempo and the click follows.
  • The playhead keeps moving during a take even when the transport isn't running, so you can click the ruler to pick a punch-in position.

MIDI + audio-input monitor

The 📊 Monitor button next to the transport toggles a compact input monitor, so you can see your keyboard and mic before you press REC.

  • 🎹 MIDI in — a mini keyboard (C3–B4 range) lights up in real time as notes arrive from the selected MIDI input, with a live log line (note · pitch · velocity · channel) under it. Works for hardware keyboards over USB MIDI.
  • 🎤 Audio input level — a green→yellow→red level bar with rms and peak dB readouts, so you can check the mic level before/while recording.
  • It shares the same MIDI input and microphone stream as ● REC — open it during a take and you'll see the same activity the recorder captures, without the two competing for the hardware.

Hum → MIDI (record the hum, then convert it)

Turn your voice into MIDI notes — recorded first, analysed after, so there's no live jitter. On the transport, toggle the green 🎙 Mic button on, then press 🎙 Rec Hum, sing/hum your bar, and tap ⬛ Stop Hum. The take lands on an audio track via daw_imports/. When you're happy:

  • Press 🎵 Hum→MIDI — it runs offline pitch detection over that recorded take and inserts the result as MIDI notes onto a MIDI track (the armed one, else the first, else it creates one), positioned where you started recording the hum.
  • Forces the selected 🎚 key and 🎼 scale — the key/scale dropdowns sit next to the button; every pitch snaps to the nearest scale tone (A Major, E Minor Pentatonic, B Blues…). Use Chromatic to keep every pitch as-is.
  • Audit the raw take — the audio clip is yours to trim/keep; re-record and re-convert as many times as you like, each conversion adds its own notes.
  • Edit the notes afterwards in the piano roll (double-click a note), or route the MIDI track to your USB hardware synth.

Note: the mic must be permitted in the browser (the 🎙 Mic button prompts once), and a steady monophonic hum works best — chords or very short blips track less reliably.

Session grid (looper)

Click 🎛 Session for a clip-launch grid — one column per track, scene rows.

  • Drag a library clip into a cell, then click the cell to loop it live through that track's chain (its volume / pan / mute / FX all apply).
  • One active cell per column — launching another in the same track replaces it; click the active cell to stop.
  • ⏹ Stop All clears everything; + Scene adds a row.
  • Free-launch (no quantization) — built for layering loops of any length on the fly. Independent of the timeline transport.

Export

⬇ Export WAV bounces the whole arrangement offline through the same graph as playback — volume, pan, mute/solo, fades, FX, and time-stretch (including pitch-lock) are all baked into a 16-bit WAV download.

Tips

  • Generate a few clips first so the library has material to arrange.
  • Set the project tempo before arranging so the snap grid matches your material.
  • Use Split to Stems on a full song, then mute/solo and re-balance the stems with the mixer + FX.
  • For tempo-matched loops in the session grid, time-stretch clips with pitch lock so they stay in key.
  • Everything is non-destructive — your original generated files are never modified; the project just references them.
