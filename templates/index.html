v3.11.0 — Browser DAW

  • 🎚 Multi-track DAW — a full in-browser digital audio workstation (Web Audio API) in the new DAW tab: drag generated clips and stems from the library onto a timeline, arrange, mix, and bounce to WAV. Projects autosave to the server and reload exactly as left.
  • Timeline arranger — move/trim clips, drag across tracks, fade-in/out handles with drawn curves, split-at-playhead, normalize, per-clip gain; zoom and ruler scrubbing
  • Mixer + per-track FX — dB faders, pan, mute/solo, level meters, master fader; each track has insert EQ (3-band) / Reverb / Delay, toggleable and persisted
  • AI operations on clips — 🤖 AI Remix (variation / extend / repaint via ACE-Step), 🎛 Split to Stems (Demucs → vocals/drums/bass/other as tracks), and 🎵 Generate onto track from the track header
  • 🎛 Session grid — a clip-launch looper: drop clips into per-track scene cells and trigger them live through each track's chain (volume/pan/mute/FX apply); one active cell per column, Stop All, + Scene
  • Snap to grid — snap clip placement, moves, trims, and stretches to a tempo grid (Bar / ½ / Beat / ¼) with visible grid lines; hold Ctrl to bypass
  • Time-stretch — Alt+drag a clip edge or enter a target %; varispeed by default (pitch follows speed) or 🔒 pitch-lock (SoundTouch) to preserve key; clamped 0.25×–4×
  • ⬇ Export WAV — bounces the arrangement offline through the same graph as playback (volume, pan, mute/solo, fades, FX, and time-stretch incl. pitch-lock all baked in)
  • Full walkthrough in Guide → 🎚 DAW

v3.10.0 — Tagging & Song-Creation Toolkit

  • Smarter lint rules — five new checks in the Lint tab: lyrics with no vocal tag, too many sections for the duration (~12 s each), genre/instrument conflicts (e.g. acoustic folk + 808 bass), overlong sung lines (>~16 syllables), and genre tags buried late in the list
  • Quality fix suggestions + ✨ Apply & Retake — 📊 Score now diagnoses weak dimensions and proposes remedy tags (bass-heavy → bright, crisp, airy; quiet → punchy, powerful); one click re-generates with the same seed plus the fixes so only the fix changes
  • 🅰/🅱 Seed A/B compare — set two takes as A and B for a side-by-side player panel with tag-diff highlighting; flags when the seeds match so you know the difference is the tags, not randomness
  • 📈 History insights — mines your scored generations to surface your best- and worst-performing tags by average quality (a tag must appear in ≥2 scored takes)
  • Artist profile — full apply — BioInfusor artist lookup now also sets Genre, Key, and Scale from the artist's vocal range, not just instruments/vocals
  • 🏷 Auto-tag from reference — Analyze tab → Suggest Tags has Ollama infer genre/style tags from detected BPM, key, chords, and lyrics
  • 🚫 Negative prompting — new Avoid field in Parameters steers the diffusion model away from named qualities (vocals, muddy bass, distortion) via negative conditioning
  • 16 Golden presets — built-in curated tag combos per genre; loading one sets the full state including the right model/steps/CFG; built-ins are protected from deletion
  • Retake works on restored jobs — 🔁 Retake and ✨ Apply & Retake now hydrate from /meta when a job card was restored after a page reload, instead of failing with "no stored parameters"
  • Security & CI hardening — repo made private with the leaked API key scrubbed from history; path-traversal guards on downloads; trusted-proxy check on the CF identity header; pinned requirements; GitHub Actions test workflow; 75 automated tests
  • Full write-up in Guide → ✨ What's New

v3.9.4 — Lyrics Parenthesis Fix

  • Parenthetical content stripped before generation — ACE-Step sings everything in the lyrics field verbatim; content like (Echoes fade out) or (oh yeah) was being performed as regular vocals. Now stripped at the server before the workflow is sent to ComfyUI.

  • Bracket tags unaffected — [Verse], [Chorus], [Guitar Solo], [Outro: Fading], etc. pass through unchanged; only round-bracket (...) content is stripped.

MIDI Tab

  • Extract MIDI from any audio file — two modes: Melody (monophonic, any instrument) and Piano (polyphonic neural)
  • Melody mode uses librosa pyin pitch detection — works on vocals, guitar, violin, synth leads, any single-note source
  • Piano mode uses Piano Transcription Inference (GPU-accelerated neural model) — captures full chords and voice leading
  • BPM field sets the MIDI tempo header for Melody mode — use the Analyze tab first to auto-detect BPM
  • Notes shorter than 50 ms are filtered automatically; output is a standard .mid file downloadable directly
  • Backend: POST /midi/extract accepts multipart upload (file + mode + bpm), returns .mid as streaming response with info headers
  • Use extracted MIDI to re-orchestrate in your DAW, study what the AI generated harmonically, or feed note data back into tag crafting
