v4.5.0 — Hum→MIDI is now record-then-convert

  • 🎙 Rec Hum — records your voice into an audio take (landed on an audio track), so you audit the raw hum before converting
  • 🎵 Hum→MIDI — runs offline pitch detection over the recorded take (no more live jitter), snaps everything into the selected 🎚 key + 🎼 scale, and drops the notes onto a MIDI track at the position you started recording
  • Key + scale forced — A…C# and Major, Minor, Pentatonic, Blues, Chromatic… every note snaps to the nearest scale tone

v4.4.0 — Mic on/off & 🎵 Hum → MIDI

  • 🎙 Mic button — one-tap mic on/off on the DAW transport (green when live), shared with recording and the monitor
  • Force a key + scale — pick key (A…C#) and scale (Major, Minor, Pentatonic, Blues…); every note snaps to the nearest scale tone

v4.3.0 — DAW Recording (MIDI-in + Audio-in)

  • 🎚 Record directly into the DAW — a red ● REC button on the DAW transport. Arm any track with the ● button on its header, press REC, and play your part
  • 🎹 MIDI-in → notes — connect a MIDI keyboard over USB; every note (with velocity) is captured into the armed MIDI track's piano-roll notes at the playhead, whether or not the transport is running
  • 🎤 Audio-in → clip — the browser microphone records directly into an audio clip on armed audio tracks, placed at the record start and added to the clip library
  • Live monitoring — internal-synth tracks play your keys in real time through the track chain (mixer + FX apply); external tracks note through the selected USB MIDI output
  • Metronome — tempo-following Click checkbox keeps you in time while recording
  • Device pickers — MIDI in and Mic selectors on the transport choose which keyboard/microphone the DAW listens to
  • Backend — POST /daw/import now accepts .webm/.mp4 (browser MediaRecorder output) alongside WAV/MP3/FLAC/OGG
  • 📊 MIDI + audio-input monitor — a 📊 Monitor panel on the transport shows live MIDI-in activity on a mini keyboard (with a note/pitch/velocity/channel log) and a real-time mic level meter (rms + peak dB), sharing the same input devices as recording

  • Radio IP no longer hardcoded — 192.168.1.236 replaced with RADIO_HOST/RADIO_PORT config vars, settable via environment variables
  • Radio stop requires auth — /radio/stop now validates the user session before stopping the stream
  • All audio formats supported for extend — _trim_for_extend uses ffprobe instead of MP3-only mutagen, so WAV/FLAC/OGG/M4A files work as remix source
  • Demucs auth added — both /stems/demucs/upload and /stems/demucs/download now require authentication
  • Duplicate SSE connection eliminated — app.js had its own connectSSE() that created a second EventSource; removed in favor of the single connection in jobs.js
  • Dead code removed — duplicate addJobCard, updateJobCard, addDownloadLinks, and statusLabel stripped from app.js; the better implementations in jobs.js (with dismiss tracking, cancel buttons, card caps, waveform players) now run without being overridden
  • SSE exponential backoff — reconnect delay starts at 1s and doubles up to 30s max, resets to 1s on successful connection
  • Negative tags in remix — the Avoid field is now wired into remix, cover, and repaint workflows
  • Email privacy — user_email removed from the all_jobs queue API response
  • Path traversal prevention — /quality/{filename} sanitizes via Path(filename).name before filesystem access
  • Stale job detection — jobs stuck in "running" or "queued" for over 30 minutes with no ComfyUI queue entry are auto-marked as error
  • RemixRequest model expanded — added negative_tags, dit_model, sampler_name, scheduler fields so the remix API supports all generation parameters
  • Parenthetical opt-out — a keep_parentheticals flag in the generate API lets you preserve (whispered), (instrumental), etc. in lyrics instead of auto-stripping them
  • Ollama retry jitter — retry sleep now includes random jitter (1 + random(0,1) seconds) to avoid thundering herd on recovery

  • 📊 Score — appears on every job card; GET /quality/{file} returns composite 0–10 + letter grade; 5 dimensions: Loudness (LUFS), Dynamics (LRA), Spectral (band ratios), Saturation (clipping), Coherence (RMS CV)
