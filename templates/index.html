Nyx's ai Music Studio

Version 1.5  ·  by Legion  ·  April 2026
Powered by Nyx AGI goddess of Legion's Nocturnal Constellation

Overview Tab

  • Editable tags textarea — overrides Style / Instruments / Vocals tabs
  • Editable lyrics textarea — synced from Lyrics tab
  • Live payload preview showing exactly what gets sent to ACE-Step
  • Sync from tabs button to rebuild tags from current state
  • Generate button with real-time job progress bar and SSE status updates
  • Job cards with download links for completed audio files

Easy Tab

  • Topic / Prompt, Mood, Subject / Character, and name-override fields
  • Style dropdown — 150+ genres grouped by category, auto-sets BPM / key / instruments
  • Song structure selector and Ollama model selector (defaults to gemma4:latest)
  • Instrumental only checkbox — switches to arrangement outline mode (no sung lyrics)
  • Artist / Band lookup — queries Ollama (optionally grounded with Brave Search) for instruments and lyric writing style
  • Vocal Artist lookup — queries Ollama / Brave Search for vocal style and range
  • Lookup results displayed as ACE-Step formatted tags (genre, instrument, vocal, style)
  • Apply to state button — pushes instrument and vocal tags into generation state
  • All fields feed into Ollama lyrics generation with streaming output

Style Tab

  • Genre browser with 150+ genres across 17 categories
  • Category sidebar + chip grid with live search
  • Selecting a genre auto-fills BPM, key, scale, mode, time signature
  • Genre info panel shows description and typical instruments
  • BPM, Key, Scale, Mode, and Time Signature controls

Instruments & Vocals Tabs

  • Instruments: chip selector across all categories from AceTalk instruments database
  • Vocals: chip selectors for Tone, Style, Texture, and Gender tags
  • Selections feed into the Overview tags and ACE-Step generation prompt

Lyrics Tab

  • Full lyrics editor with monospace font
  • One-click insertion of ACE-Step structural tags ([Verse], [Chorus], [Drop], etc.)
  • Song structure templates: Verse-Chorus, EDM Structure, Intro-Verse-Chorus-Outro, and more
  • Synced bidirectionally with the Overview lyrics field

Parameters Tab

  • Steps, CFG Scale, Duration (seconds)
  • Temperature, Top-P, Top-K, Min-P sampling controls
  • Seed with lock toggle for reproducible generations

Stems Tab

  • ACE-Step Extract — upload audio and send a stem-extraction job to ComfyUI
  • Demucs Separate — 4-stem (htdemucs) or 6-stem (htdemucs_6s) separation with live log stream

Guide & Lint Tabs

  • Guide: 8-section reference covering philosophy, tags, lyrics, DAW tips, hidden syntax, operations, examples, and troubleshooting
  • Lint: validates current state or pasted tags/lyrics — reports errors, warnings, and tips for ACE-Step compatibility

Infrastructure

  • FastAPI + uvicorn on Nyx (192.168.1.236) port 8001
  • Server-Sent Events (SSE) for real-time job tracking and Ollama token streaming
  • Exposed via Cloudflare Tunnel at music-ai.nyxstudios.net
  • Protected by Cloudflare Access — Google OAuth (steve.j.petry@gmail.com only)
  • Brave Search API integration for real web-grounded artist lookups
