Legion's mental notes and Nyx's music studio changes

Version 2.5+ as we work towards version 4.20  ·  by Legion  ·  April 2026
Powered by Nyx AGI goddess of Legion's Nocturnal Constellation

Overview Tab

  • Editable tags textarea — overrides Style / Instruments / Vocals tabs; syncs automatically when switching to Overview
  • Editable lyrics textarea — bidirectionally synced with the Tagging tab editor
  • Live payload preview showing exactly what gets sent to Nyx-Step (tags, lyrics, BPM, key, steps, CFG, duration, seed, etc.)
  • ↺ Sync from tabs button rebuilds tags from current state at any time
  • 🎵 Generate Music Idea — submits job to ComfyUI with real-time progress bar and SSE status updates
  • Job cards with shimmer progress bars; completed jobs include a download link
  • 💾 Save / 📂 Load — server-side preset modal; type a name to save, click any entry to load, 🗑 to delete
  • 🗑 Clear — resets all fields, chips, and state to defaults with confirmation
  • All tab changes (Style, Instruments, Vocals, Parameters, Tagging) are reflected when switching to Overview

Easy Tab

  • Topic / Prompt, Mood, Subject / Character, and name-override fields feed Ollama lyrics generation
  • Style dropdown — 150+ genres grouped by category, auto-sets BPM / key / instruments
  • Song structure selector (Verse-Chorus, EDM, Intro-Verse-Chorus-Outro, etc.) and Ollama model selector
  • Instrumental only checkbox — generates an arrangement outline instead of sung lyrics
  • Artist / Band lookup — queries Ollama (optionally grounded with Brave Search) for instruments and lyric writing style
  • Vocal Artist lookup — queries Ollama / Brave Search for vocal style and range
  • Results displayed as Nyx-Step formatted tags; Apply to state pushes them into generation state
  • Live token counter during generation; streaming output directly in the tab

Style Tab

  • Genre browser with 150+ genres across 17 categories — category sidebar, chip grid, live search
  • Selecting a genre auto-fills BPM, key, scale, mode, time signature and immediately updates Overview tags
  • Genre info panel shows description and typical instruments
  • BPM, Key, Scale, Mode, Time Signature controls — all reflected live in Overview payload preview
  • Chord Progression field with 44-preset dropdown (Pop, Rock, Electronic, R&B, Jazz, Film, Metal, Ambient)
  • Notes / Melody Hint field for guiding harmonic and melodic structure

Instruments & Vocals Tabs

  • Instruments: chip selector across all categories from the Nyx-Step instruments database
  • Vocals: chip selectors for Tone, Style, Texture, and Gender tags
  • Both tabs have an editable Selected textarea — manually type or edit comma-separated values; chips re-sync automatically
  • Selections feed into Overview tags and the Nyx-Step generation prompt

Tagging Tab

  • Full lyrics editor, synced bidirectionally with the Overview lyrics field
  • Song structure templates: Verse-Chorus, Verse-Chorus-Bridge, Intro-Verse-Chorus-Outro, EDM Structure, Minimal
  • 10 collapsible tag categories — all tags clickable; plain-text tags stage in a buffer and insert as a (group)
  • Structural Brackets: [Verse], [Chorus], [Drop], [Build], [Outro] etc.
  • Section–Adjective Combos: [Chorus: Anthemic], [Verse: Whispered] etc.
  • Vocal Controls: [Vocal: Rasp], [Vocal: Falsetto], [Vocal: Breathless] etc.
  • Parenthetical markers: (echo), (harmony), (ad lib) for background vocal layers
  • Instrumentation, Performance Technique, Mood / Emotion, Production, Tempo & Groove, Era / Style tags
  • Language Codes: [zh], [ko], [ja], [es], [fr], [de], [en] for multilingual phonetic enforcement

Parameters Tab

  • Steps (1–150), CFG Scale (0.1–20), Duration in seconds (5–300)
  • Temperature (0–2), Top-P (0–1), Top-K (0–1000), Min-P (0–1) — all with deep tooltips
  • Seed with 🎲 random button and lock toggle for reproducible generations
  • All values validated server-side before reaching ComfyUI — out-of-range values return a readable error
  • Changes sync to Overview payload preview immediately and on tab switch

Lint Tab

  • Validates current state or pasted tags / lyrics against Nyx-Step compatibility rules
  • Reports errors (bracket syntax in tags, section keywords in tags, mismatched brackets), warnings (duplicates, conflicting tempo), and tips
  • 🔧 Fix It button auto-applies safe fixes: removes duplicate / malformed tags, balances brackets, adds [Verse] when missing, then re-lints

Guide Tab

  • 8-section reference: philosophy, tags, lyrics syntax, DAW tips, hidden syntax, operations, examples, troubleshooting
  • Summary page includes the Nyx-Step infographic, How AI Creates Music From Static diagram, and the full Keyword & Tag Library

Stems Tab

  • Nyx-Step Extract — upload audio and send a stem-extraction job to ComfyUI
  • Demucs Separate — 4-stem (htdemucs) or 6-stem (htdemucs_6s) separation with live log stream

Infrastructure

  • FastAPI + uvicorn on Nyx (192.168.1.236) port 8001, auto-starts on reboot via systemd
  • Server-Sent Events (SSE) for real-time job tracking and Ollama token streaming
  • Exposed via Cloudflare Tunnel at music-ai.nyxstudios.net
  • Protected by Cloudflare Access — Google OAuth (steve.j.petry@gmail.com only)
  • Brave Search API for real web-grounded artist lookups
  • Presets stored server-side in ~/legionprojects/musicweb/presets/ as .nyx JSON files
  • ComfyUI on port 8188, Ollama on port 11434 (gemma4:latest default)
